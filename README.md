# Body Parts — удаление татуировок

Статичная адаптивная страница, подготовленная для GitHub Pages.

## Локальный просмотр

В папке проекта выполните:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий GitHub и загрузите в него все файлы этой папки.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/(root)`.
5. После публикации страница будет доступна по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Для личного адреса без имени репозитория назовите репозиторий `ВАШ-ЛОГИН.github.io`.

## Что заменить перед запуском

- Добавьте реальные фото в зоны с `data-media` в `index.html` / `src/style.css`.
- Замените `VIDEO_ID` в атрибутах `data-video` на идентификаторы видео YouTube или Rutube.
- Подключите настоящую форму или ссылку на мессенджер вместо демонстрационного купона в `src/main.js`.
